# sql/ 数据库手动变更目录

本目录存放生产环境的**纯 SQL 手动变更脚本**（不使用 TypeORM migration 或任何迁移库）。

## 使用规则

1. 文件按序号顺序在生产环境**手动执行**：`001_xxx.sql` → `002_xxx.sql` → ……，序号即执行顺序，禁止跳号、重号。
2. **执行前必须备份**相关表（结构 + 数据），并在低峰期执行；索引变更虽不锁表改数据，MySQL 5.7 下 InnoDB 加索引仍会消耗 IO 并短暂影响写入。
3. SQL 变更必须**与代码同一个 PR 提交**：实体装饰器变更只在开发环境经 `synchronize` 自动同步，生产环境 `synchronize` 永久关闭，不执行本目录脚本会导致代码与表结构不一致。
4. 所有脚本按 **MySQL 5.7** 语法编写，并做**幂等处理**（通过 `information_schema` 检查列/索引是否存在后再执行 DDL），可重复执行不报错。
5. 开发环境依赖 TypeORM `synchronize` 自动同步实体结构，**无需执行**本目录脚本。
