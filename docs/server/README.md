# 小绿记账 · 服务端开发文档

> 版本：v1.0　|　最后更新：2026-09-16　|　适用客户端：uni-app（App / H5 / 小程序）
>
> 本文档是「小绿记账」由**纯本地存储（Pinia + 本地持久化）架构**改造为**前后端分离、基于 RESTful API 调用架构**的唯一设计依据，可直接用于服务端工程脚手架生成与逐模块开发。

## 一、改造范围与边界

### 1.1 本次纳入 API 化改造的模块

| 客户端现状（本地）                                     | 改造后服务端模块            | 说明                               |
| --------------------------------------------- | ------------------- | -------------------------------- |
| `store/modules/user.js`（昵称/头像/加入日期）           | auth、users          | 新增注册/登录体系，资料服务端存储                |
| `store/modules/book.js`（账本/预算/支付方式字典）         | books、dictionaries  | 多账本按用户隔离；支付方式元数据为系统字典            |
| `store/modules/category.js`（收支分类字典）           | dictionaries        | 9 个支出分类 + 7 个收入分类入库为种子数据         |
| `store/modules/bill.js`（账单增删改查/月汇总/聚合）        | bills、statistics    | 核心业务，全部查询由 SQL 聚合完成              |
| `composables/useBookkeeping.js`（首页/流水/统计派生数据） | statistics、overview | 首页概览、流水分组、统计排行、趋势                |
| 账单凭证图片（base64 本地存储）                           | uploads             | 改为服务端本地磁盘存储（`UPLOAD_DIR`，文件名有意义），库中只存相对路径 key，访问走服务端签名 URL |
| `store/modules/app.js`（轻量 UI 选择态）             | users（preferences）  | 可选：跨设备同步；不接入时仍可纯本地保留             |

### 1.2 明确排除：APP 在线更新系统

以下能力**保持现状、独立部署、不在本次改造范围内**，服务端新工程不为其开发任何接口：

- 检查更新接口：`POST {UPDATE_BASE_URL}/app-updates/check`（现网地址 `https://static.shixian.xyz/static`，开发联调 `http://192.168.1.13:9867/static`）
- APK 下载地址下发、安装结果/埋点事件上报（`utils/app-update/reporter.js`）
- 客户端对应代码：`composables/use-app-update.js`、`components/update-popup.vue`、`utils/app-update/*`

两套系统的域名、端口、鉴权体系完全独立。客户端新 API 客户端（`Authorization: Bearer`）不得复用更新模块的 `request` 封装。

### 1.3 暂不实现的占位功能

「我的」页中**邀请好友、记账提醒、意见反馈、关于我们、设置、消息铃铛**当前仅为 toast 占位，本次不设计对应服务端接口；后续如产品立项再补充。

## 三、关键业务口径（全系统必须一致）

以下口径源自客户端现有实现，服务端实现**不得擅自变更**：

1. **金额**：账单金额恒为正数（`DECIMAL(12,2)`），方向由 `type = expense | income` 表达；接口对 C 端返回时支出可带负号（视图模型），入库永远为正。
2. **舍入**：金额保留两位小数，统一「先乘 100 四舍五入再除回」，禁止浮点累加。
3. **日期时间**：记账日期 `YYYY-MM-DD`、时间 `HH:mm`；按「日期倒序 → 时间倒序 → 创建时间倒序」排列。
4. **备注**最长 50 字；**凭证图片**最多 3 张。
5. **账本名**最长 12 字；**昵称**最长 12 字；预算必须 ≥ 0，0 表示未设置。
6. **分类非法时**（字典中不存在）服务端直接判 400，不再像本地版那样静默回退「其他」（API 化后属于客户端 Bug，应显性暴露）。
7. 每个用户注册时自动创建唯一默认账本「个人账本」（budget=0），默认账本不可删除。
